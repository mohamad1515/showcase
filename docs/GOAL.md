# هدف پروژه

هدف این پروژه ساخت یک فروشگاه اینترنتی حرفه ای و قابل توسعه است که شامل:

- مدیریت محصولات (ایجاد، ویرایش، حذف، فهرست)
- مدیریت دسته‌بندی‌ها و اسلایدرها
- احراز هویت کاربران و مدیریت کاربران ادمین/کاربر
- آپلود تصاویر برای محصولات و اسلایدر
- نمایش فروشگاه در سمت کاربر و پنل مدیریت در سمت ادمین

این پروژه به‌صورت Full-stack با بک‌اند نِست (GraphQL) و فرانت‌اند Next.js پیاده‌سازی شده است و هدفش پایه‌ای قابل توسعه برای اضافه کردن ویژگی‌های فروشگاهی (سفارشات، پرداخت، سبد خرید و غیره) می‌باشد.
