# بخش‌های ناقص / جاهایی که هنوز کامل نشده‌اند

موارد زیر در این پروژه به‌صورت کامل وجود ندارند یا نیاز به توسعه و تکمیل دارند:

- مدیریت سفارشات و سبد خرید: مدل، API و صفحات فرانت‌اند برای سبد خرید و تسویه
- درگاه پرداخت: پیاده‌سازی پرداخت (مثلاً Stripe یا درگاه‌های ایرانی)
- سیستم انبارداری و موجودی: پیگیری موجودی کالاها و مدیریت شمار موجودی
- صفحات و عملیات مشتری: تاریخچه سفارشات، پروفایل کامل کاربر، بازیابی رمز عبور
- جستجو و فیلتر محصولات: فیلتر بر اساس دسته، قیمت، برچسب و سرچ
- pagination و بهینه‌سازی کوئری‌ها برای لیست‌های بزرگ
- کش (Cache) و افزایش عملکرد: استفاده از Redis یا CDN برای محتوا
- بهبود امنیت: rate-limiting، hardening JWT/سرور، تنظیمات CORS کامل
- مانیتورینگ و لاگینگ: Sentry، لاگ‌های ساختاریافته
- تست‌ها: تست‌های واحد (unit) و انتها تا انتها (e2e)
- CI/CD و استقرار: اسکریپت‌ها و مستندات استقرار خودکار
- بهینه‌سازی تصاویر و مدیریت CDN برای آپلودها
- متادیتا و SEO: تگ‌های meta، sitemap، Open Graph
- دسترسی‌پذیری (a11y) و تست‌های مربوطه

موارد بالا برای تبدیل پروژه از یک نمونهٔ showcase به یک فروشگاه production-ready لازم هستند.
