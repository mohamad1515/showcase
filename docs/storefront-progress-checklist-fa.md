# چک‌لیست پیشرفت تکمیل فروشگاه

این فایل مرجع پیگیری تغییرات واقعی مخزن است. پس از هر مرحله، وضعیت و یادداشت‌ها به‌روزرسانی می‌شوند.

## انجام‌شده

- [x] بررسی اولیهٔ ساختار فروشگاه، صفحات، پنل مدیریت و برنامهٔ اجرا.
- [x] حذف بخش اشتراک ماهانه/سالانهٔ «طرح‌ها» از صفحهٔ اصلی و حذف کامپوننت بلااستفاده.
- [x] حذف آمار نمونه و ادعاهای ثابتِ قابل‌اثبات‌نبودنی از خانه؛ جایگزینی برخی متن‌های معرفی با توضیح خنثی.
- [x] حذف نشانی و شماره‌تلفن نمونه از فوتر و ارجاع به صفحهٔ تماس.
- [x] افزودن فیلدهای اختیاری ترکیبات، اطلاعات تغذیه‌ای، روش مصرف درج‌شده روی محصول و هشدارها به مدل محصول، پایگاه داده، GraphQL و فرم ادمین.
- [x] نمایش این اطلاعات در صفحهٔ محصول فقط وقتی برای کالا ثبت شده باشند.
- [x] افزودن برند و طعم به مشخصات صفحهٔ محصول.
- [x] افزودن سازنده، کشور مبدأ، اندازه/تعداد وعده، شناسهٔ رهگیری و توضیح انقضا به پنل، API و صفحهٔ محصول.

## انجام‌شده در مرحلهٔ جاری: کاتالوگ و جستجو

- [x] افزودن فیلتر برند و طعم به کاتالوگ؛ گزینه‌ها از اطلاعات ثبت‌شدهٔ محصولات ساخته می‌شوند.
- [x] افزودن صفحهٔ `/search?q=...` با URL قابل کپی/اشتراک و نتایج فیلترشده.
- [x] گسترش جستجوی هدر به نام فارسی/انگلیسی، برند، طعم، برچسب و خلاصه؛ Enter و پیوند نتایج به صفحهٔ کامل می‌روند.
- [x] ساخت فهرست برندهای دارای محصول و صفحهٔ اختصاصی هر برند؛ لینک «برندها» به منوی اصلی افزوده شد.
- [x] افزودن فیلتر وزن با نرمال‌سازی گرم/کیلوگرم از مقدار فعلی وزن محصول.
- [x] افزودن مرتب‌سازی پرفروش با تعداد اقلام سفارش‌هایی که وضعیت پرداخت‌شده یا ارسال‌شده دارند.
- [x] ساخت صفحهٔ مدیریت سفارش، نمایش اقلام/مبلغ و تغییر وضعیت با دسترسی مدیر و انتقال‌های مجاز.
- [x] افزودن پروفایل مشتری با مشاهدهٔ ایمیل و ویرایش نام؛ لینک حساب برای مشتری عادی به پروفایل می‌رود و برای مدیر به پنل.
- [x] افزودن صفحهٔ جزئیات سفارشِ کاربر واردشده و لینک از تاریخچهٔ سفارش‌ها.

## نیازمند اطلاعات کسب‌وکار برای ادامه

- [ ] مرحلهٔ ۳: اتصال درگاه پرداخت واقعی و قواعد ارسال؛ در مخزن درگاه یا تنظیمات ارسال پیکربندی نشده است.
- [ ] موارد لازم برای تکمیل امن: نام درگاه انتخابی و دسترسی/راهنمای فنی آن، شهرها و روش‌های ارسال قابل ارائه، هزینه یا قاعدهٔ محاسبهٔ ارسال، و شرایط آستانهٔ ارسال رایگان در صورت وجود.

## باقی‌مانده

- [ ] تکمیل موارد مرحلهٔ ۱: تاریخ بچ/انقضای دقیق برای هر سری موجودی، تصاویر واقعیِ بسته و برچسب، صفحهٔ مجوز و اصالت و سیاست‌های فروشگاه.
- [x] مرحلهٔ ۲: جستجو، برند، طعم، وزن، فهرست/صفحهٔ برند و مرتب‌سازی پرفروش بر پایهٔ سفارش‌های پرداخت‌شده/ارسال‌شده تکمیل شد.
- [ ] مرحلهٔ ۳: تسویه‌حساب، هزینه/روش ارسال، پرداخت واقعی سمت سرور، اعتبارسنجی callback و وضعیت سفارش (وابسته به ورودی‌های بالا).
- [ ] مرحلهٔ ۴: افزودن نشانی‌های مشتری و پیگیری کد رهگیری؛ API نشانی و کد رهگیری هنوز وجود ندارد.
- [ ] مرحلهٔ ۵: جستجو/فیلتر سفارش در پنل، ثبت کد رهگیری و تکمیل شاخص‌های واقعی داشبورد (فهرست سفارش و تغییر وضعیت پایه انجام شد).
- [ ] مرحلهٔ ۶: صفحات سیاست‌ها، راهنما و محتوای آموزشی بازبینی‌شده.
- [ ] مرحلهٔ ۷: سئو، دسترس‌پذیری، عملکرد و بازبینی پیش از عرضه.

## محدودیت‌ها و وابستگی‌ها

- اطلاعات محصول مثل ترکیبات و هشدارها اکنون قابل ثبت‌اند؛ دادهٔ هر محصول باید از برچسب/منبع معتبر توسط مدیر وارد شود.
- درگاه پرداخت و قواعد ارسال واقعی به انتخاب و اطلاعات کسب‌وکار وابسته‌اند؛ تا فراهم‌شدن آن‌ها نباید سفارش پرداخت‌شده وانمود شود.
- انتقال وضعیت سفارش در پنل محدود است: سفارش در انتظار پرداخت فقط لغو می‌شود؛ سفارش پرداخت‌شده می‌تواند ارسال یا لغو شود؛ وضعیت پرداخت‌شده از پنل جعل نمی‌شود.
- مواردی مثل پرفروش‌ترین باید بر پایهٔ دادهٔ فروش واقعی پیاده شوند.

## تغییرات درخواست‌شده در ۲۰۲۶-۱۰-۳۰

- [x] افزودن seed تکرارپذیر ۱۰ محصول، ۱۰ برند و ۱۰ طعم نمونه؛ رکوردهای موجود حذف یا overwrite نمی‌شوند.
- [x] برچسب «نمونه» روی کالاهای seed‌شده برای جلوگیری از اشتباه گرفتن جزئیات نمونه با اطلاعات قطعی محصول واقعی.
- [x] پاک‌کردن token نامعتبر/منقضی، sync کردن وضعیت حساب و هدایت افزودن به سبد به ورود مجدد به‌جای خطای خام Invalid session.
- [x] حذف حالت شیشه‌ای پنل کناری سبد؛ استفاده از سطح ثابت تم و پس‌زمینهٔ تیره برای تمرکز روی drawer.
- [x] اتصال تم داشبورد ادمین به متغیرهای مشترک تم سایت تا تم تیره از همان پالت استفاده کند.
- [x] یکسان‌کردن رنگ دکمهٔ ویرایش اسلایدر با دکمهٔ ویرایش کاربر.
- [x] اجرای seed روی بک‌اند فعال؛ GraphQL پس از راه‌اندازی مجدد backend، ۱۰ محصول نمونه، ۱۰ برند نمونه و ۱۰ طعم نمونه برگرداند (یک محصول و برند قبلی هم موجود بود).
- [ ] راه‌اندازی مجدد فرانت‌اند dev برای رفع HTTP 500 فعلی روی `localhost:3000/products`؛ فرمان restart فرایند فعال توسط سیاست ابزار رد شد و فرایند دست‌نخورده ماند.
- [x] یکسان‌کردن ظاهر و رنگ دکمه‌های ویرایش جدول‌های کاربران، اسلایدرها، برندها، طعم‌ها و دسته‌بندی‌ها با دکمهٔ ویرایش جدول محصولات.
- [x] افزودن دسته‌بندی اختصاصی برای هر یک از ۱۰ محصول نمونه و انتقال رکوردهای seed‌شدهٔ قبلی به دستهٔ درست.
- [x] نمایش نام دسته‌بندی به‌جای برچسب «نمونه» روی کارت و صفحهٔ محصول.
- [x] جایگزینی مسیر تصویر کراتین با فایل تصویر دارای نام درست و اصلاح رکورد قبلی در راه‌اندازی دیتابیس.
- [x] نمایش امتیاز اولیهٔ ۵ برای محصول بدون نظر و محاسبهٔ امتیاز با ۱۰ امتیاز پایهٔ پنج‌ستاره؛ کف امتیاز ۱ است.
- [x] بازچینی صفحهٔ محصول: جزئیات سمت راست، گالری و تصاویر کوچک سمت چپ، خلاصه و حداکثر ۹ ویژگی در ردیف‌های سه‌تایی، قیمت با جداکنندهٔ سه‌رقمی و موجودی کنار قیمت.
- [x] محدودکردن تب‌های محصول به توضیحات (با روش مصرف)، مشخصات (با ترکیبات) و نظرات؛ متن محصول بدون نظر فقط در باکس خالی نظرات نمایش داده می‌شود.
- [x] نمایش محصولات مرتبط از دستهٔ یکسان و در صورت نبودن، از نوع محصول یکسان.
- [x] تبدیل بخش «خرید بر اساس دسته‌بندی» به carousel بدون نوار اسکرول؛ فلش‌ها یک کارت را جابه‌جا می‌کنند، کشیدن با ماوس/لمس فعال است و چرخه در صورت داشتن دسته‌های کافی حلقه‌ای می‌شود (۵ دسته در دسکتاپ).
- [x] تبدیل محصولات مرتبط به carousel حلقه‌ای با کشیدن و فلش‌های قبلی/بعدی؛ حداکثر ۶ محصول تصادفی با اولویت دسته و نوع یکسان نمایش داده می‌شود.
- [x] قرارگرفتن عنوان دسته‌بندی کنار نشان نوع محصول در صفحهٔ جزئیات محصول.
- [x] حذف محصول‌های تکراری از منبع داده و خود carousel مرتبط؛ تکرار بر اساس شناسه/slug و مشخصات یکسان (نام، برند، وزن و طعم) شناسایی می‌شود.
- [x] صریح‌کردن drag با ماوس/لمس و مخفی‌بودن scrollbar در carousel «خرید بر اساس دسته‌بندی»؛ حرکت فلش‌ها یک کارت و سرعت چرخه تنظیم شد.
- [x] ساخت production فرانت‌اند و بک‌اند؛ تعیین صریح ریشهٔ Turbopack در `frontend/next.config.ts` برای حذف هشدار تشخیص چند lockfile.
