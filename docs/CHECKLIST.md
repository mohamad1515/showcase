# چک‌لیست مرحله‌ای برای تکمیل پروژه

این فایل شامل تسک‌های قدم‌به‌قدم برای موارد ناقص است تا بتوانید مرحله‌ای آن‌ها را پیاده‌سازی کنید.

## الویت: بالا — MVP

1. سبد خرید (Cart) ✅
   - طراحی مدل: `Cart`, `CartItem` در بک‌اند
   - GraphQL: اضافه کردن mutationها برای افزودن/حذف/به‌روز‌رسانی آیتم‌ها
   - فرانت‌اند: صفحه/کامپوننت Cart و دکمه افزودن به سبد در `ProductCard`
   - تست: تست‌های واحد ساده برای منطق جمع‌زدن قیمت

2. سفارشات (Orders) ✅
   - مدل Order و OrderItem، وضعیت‌ها (pending, paid, shipped, canceled)
   - API: mutation برای ایجاد سفارش از سبد و query برای تاریخچه سفارشات کاربر
   - فرانت‌اند: صفحه ثبت سفارش از سبد و صفحه تاریخچه سفارشات

3. درگاه پرداخت
   - انتخاب سرویس (Stripe یا PSP محلی)
   - پیاده‌سازی سروری برای ایجاد پرداخت‌ها و webhookها
   - اتصال فرانت‌اند به پرداخت و بررسی وضعیت پرداخت در بک‌اند

4. مدیریت موجودی ✅ پایه
   - افزودن فیلد `stock` به محصول
   - بررسی موجودی قبل از افزودن به سبد/ایجاد سفارش و کاهش موجودی هنگام ثبت سفارش فعلی

## الویت: متوسط — عملکرد و اعتماد

5. کش و CDN
   - اضافه کردن Redis برای کش نتایج پرهزینه (لیست محصولات، session)
   - آپلود تصاویر به سرویس استاتیک یا CDN (مثلاً S3 + CloudFront)

6. لاگینگ و مانیتورینگ
   - اضافه کردن Sentry برای خطاها
   - تعریف لاگ‌های ساختاریافته و retention مناسب

7. Pagination و بهینه‌سازی کوئری‌ها
   - اضافه کردن pagination به لیست محصولات و دسته‌ها
   - استفاده از DataLoader / batching در GraphQL اگر لازم است

## الویت: کم — تجربه کاربری و رشد

8. جستجو و فیلترها
   - API برای فیلتر بر اساس دسته، قیمت، برچسب
   - فرانت‌اند: رابط فیلتر و مرتب‌سازی

9. SEO و متادیتا
   - افزودن meta tags، sitemap.xml و Open Graph

10. بررسی‌ها، تخفیف‌ها و ایمیل‌ها

- مدل نقد و بررسی محصول
- ساخت سیستم کد تخفیف ساده
- ارسال ایمیل اطلاع‌رسانی (نوتیفیکیشن سفارش، بازیابی رمز)

## کیفیت کد و استقرار

11. تست‌ها

- نوشتن تست‌های واحد با Jest برای منطق بک‌اند
- اضافه کردن تست‌های e2e با Playwright/Cypress برای مسیرهای حیاتی (خرید)

12. CI/CD

- تعریف pipeline برای lint → test → build → deploy (GitHub Actions)

13. مستندسازی env و استقرار

- مستند کردن متغیرهای محیطی مورد نیاز و دستورالعمل استقرار staging/production
